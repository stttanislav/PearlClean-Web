# PearlClean Web

Встановлюваний вебдодаток (PWA), створений окремо від iOS-проєкту. Дані сеансів і налаштування зберігаються локально в браузері користувача.

## Локальний перегляд

```sh
cd /Users/stanislavgrebenuk/Desktop/PearlClean-Web
python3 -m http.server 4173
```

Потім відкрийте `http://localhost:4173`.

## Встановлення на iPhone

Після розміщення сайту на HTTPS-домені відкрийте його в Safari, натисніть «Додати на екран», а в системному меню Safari виберіть «На екран “Початок”». Ярлик PearlClean працюватиме як окремий застосунок і зберігатиме дані локально.

## Обмеження вебплатформи

- Apple Health і синхронізація з Apple Watch доступні лише нативному iOS-застосунку.
- Нагадування залежать від дозволу браузера; браузер не гарантує фонове доставлення за розкладом без сервера push-сповіщень.
- Для офлайн-роботи, Service Worker і встановлення PWA потрібен HTTPS (або `localhost` під час розробки).
